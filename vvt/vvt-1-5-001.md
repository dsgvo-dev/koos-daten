# Telekommunikationsanlagen (Telefonie)

## Technische und organisatorische Maßnahmen

- Zugriffsschutz: persönliches Passwort, Verschlüsselung
- Zugriffsprotokollierung: Datum, Uhrzeit, Person, Grund jedes Zugriffs
- Netzsegmentierung: Telefonanlage getrennt vom Verwaltungsnetz
- Verpflichtung auf Datengeheimnis + Fernmeldegeheimnis (§ 3 TDDDG)
- Vier-Augen-Prinzip bei Einsichtnahme in Verbindungsdaten
- Sperrung von Mehrwertdiensten (018xx, 0190x) standardmäßig
- Keine Speicherung von Inhaltsdaten (gesprochenes Wort)
- Keine Aufzeichnung ankommender Verbindungen
- Sonderanschlüsse (PR/DSB/SBV): keine Einzelverbindungsdaten
